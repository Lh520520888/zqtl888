# MatchPulse 浏览器插件 - 手机版兼容性修复说明

## 修复内容

本次更新修复了以下两个问题：

### 1. 配置页面无法滚动/滑动
**问题原因：** 之前的 CSS 设置 `body { overflow: hidden; }` 导致在手机浏览器上无法滚动查看下方的配置项。

**修复方案：**
- 修改了 `popup.html` 中的 CSS
- 改为 `overflow-y: auto` 允许垂直滚动
- 添加了 `min-height: 100vh` 确保内容可以正确显示
- 优化了 `html` 和 `body` 的样式设置

### 2. 音效上传不工作
**问题原因：** 手机浏览器对触摸事件的处理与桌面端不同，仅绑定了 `click` 事件。

**修复方案：**
- 修改了 `popup.js` 中的上传和重置按钮事件绑定
- 同时添加了 `click` 和 `touchstart` 两个事件监听器
- 添加了 `preventDefault()` 和 `stopPropagation()` 防止事件冲突
- 添加了文件存在性检查确保在移动端正确处理文件选择
- 优化了 `input[type="file"]` 的样式以提高移动端兼容性

## 如何重新打包 CRX

如果需要在本地生成新的 CRX 文件，请按以下步骤操作：

### 方法一：使用 Chrome 浏览器（推荐）
1. 打开 Chrome 浏览器，访问 `chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「打包扩展程序」
4. 选择扩展目录：`dist_b488693` 或 `dist_b488693_obfuscated`
5. 选择私钥文件：`dist_b488693.pem`（确保在同一目录下）
6. 点击「打包扩展程序」，即可生成新的 CRX 文件

### 方法二：使用 ZIP 文件作为替代
- 也可以直接将 `dist_b488693` 文件夹压缩为 ZIP 文件
- 在手机浏览器中（如 Quetta、Kiwi）支持直接安装 ZIP 格式的扩展
- 安装时选择「从文件安装」，选择压缩包即可
